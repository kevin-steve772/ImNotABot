# I'm Not a Bot

一个基于浏览器 Canvas 的动态噪声人机验证页面。用户观察噪声运动方向，识别由反向移动噪声构成的三个隐藏字母并输入答案。

## 功能

- 背景噪声与字母区域噪声以相反方向移动。
- 噪声使用相同的方块样式，并按区域面积保持近似一致的密度。
- 可以刷新挑战；输入会自动转换为大写并限制为三个英文字母。
- 提供输入错误和验证结果提示，并适配窄屏布局。
- 无需安装依赖或构建工具。

## 运行

直接在浏览器中打开 [`index.html`](index.html) 即可使用。

## 安全说明

这是一个前端交互演示。挑战答案由浏览器生成和校验，不能抵御能够读取页面脚本或状态的自动化程序。生产环境应由服务端生成挑战、保存答案并执行校验，同时加入有效期、重试限制等防护。
